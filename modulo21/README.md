# Módulo 21 - Testes Unitários com Jest

Exercício de criação de testes unitários para as funções desenvolvidas no Módulo 20.

## Cobertura

Foram implementados testes para:

- cálculo do MDC;
- identificação dos índices do maior e do menor valor;
- soma dos múltiplos de 5 ou 7 abaixo de 1000.

Os testes importam diretamente as funções da pasta `modulo20`.

## Tecnologia

- Jest
- JavaScript

## Execução

Instale as dependências:

```bash
npm install
```

Execute os testes:

```bash
npm test
```
