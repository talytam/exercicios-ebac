# Módulo 13 - Testes de API com Postman

Exercício de testes de API utilizando uma collection do Postman.

## Cenários

A collection contempla operações relacionadas a autenticação e usuários, incluindo:

- login válido e inválido;
- listagem de usuários;
- cadastro de usuário;
- consulta de usuário por ID;
- usuário não encontrado;
- edição de usuário;
- exclusão de usuário.

As requisições possuem validações de status HTTP e mensagens de resposta.

## Arquivo

`Exercicio Teste de API.postman_collection.json`

## Execução

Importe a collection no Postman e configure a variável `local` com a URL base da API utilizada no exercício.
