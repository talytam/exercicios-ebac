# Módulo 20 - Lógica de Programação com JavaScript

Exercícios de lógica de programação desenvolvidos em JavaScript.

## Exercícios

- `calcularMDC.js` - cálculo do máximo divisor comum entre dois números;
- `encontrarIndices.js` - identificação dos índices do maior e do menor valor de uma lista;
- `somarMultiplos.js` - soma dos múltiplos de 5 ou 7 abaixo de 1000.

As funções são exportadas para reutilização nos testes unitários do Módulo 21.
