# Módulo 10 - Git

Exercício introdutório de versionamento com Git realizado durante a formação de Engenharia de Qualidade de Software da EBAC.

## Objetivo

Praticar operações básicas do Git, incluindo criação e alteração de arquivos, commits e clonagem de repositório.

## Arquivos

- `index.html` - arquivo HTML utilizado na prática;
- `style.css` - arquivo de estilos utilizado na prática;
- `exemplo.txt` - arquivo de apoio do exercício.
