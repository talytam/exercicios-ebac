## Práticas e tecnologias

Durante os módulos foram trabalhados conceitos e práticas relacionados a **planejamento e técnicas de teste, metodologias ágeis, testes funcionais, automação Web, API e Mobile, integração contínua, performance, banco de dados e segurança**.

Entre as tecnologias e ferramentas utilizadas estão **Cypress, Gherkin/BDD, Jest, PactumJS, GraphQL, Pactum Flow, JMeter, k6, Appium, WebdriverIO, XCUITest, Sauce Labs, BrowserStack, GitHub Actions, GitHub Pages, Docker, SQL, MongoDB e Cypress Cloud**.

## Organização

Cada diretório `moduloXX` contém os exercícios correspondentes ao respectivo módulo da formação.

Alguns módulos utilizam repositórios próprios quando a atividade exige um projeto separado ou uma configuração independente. Nesses casos, o diretório do módulo mantém a documentação e as referências necessárias para a entrega.
