# Engenharia de Qualidade de Software — EBAC

Repositório destinado aos exercícios e atividades práticas desenvolvidos durante a formação **Profissão: Engenheiro de Qualidade de Software**, da EBAC.

Os conteúdos estão organizados por módulo e acompanham minha evolução desde os fundamentos de Qualidade de Software até automação de testes Web, API, DevOps e Mobile.

## Práticas e tecnologias

Durante os módulos foram trabalhados conceitos e práticas relacionados a **Qualidade de Software, planejamento e técnicas de testes, metodologias ágeis, testes de interface, Git, Cypress, testes de API, contratos de API, automação REST, integração contínua, Jenkins, Android, WebdriverIO e Appium**.

Os exercícios incluem documentação de testes, cenários funcionais, automação Web e API, configuração de pipelines e automação de testes Mobile.

## Organização

Cada diretório `moduloXX` contém os exercícios correspondentes ao respectivo módulo da formação.

Alguns módulos possuem projetos completos de automação com suas próprias configurações, dependências e documentação.
