# Módulo 24 - Automação de API

Exercício desenvolvido utilizando PactumJS, Mocha, GraphQL e Pactum Flow.

Neste módulo foram implementados testes automatizados para:

- Autenticação;
- Categorias: `addCategory`, `editCategory` e `deleteCategory`;
- Produtos: `addProduct`, `editProduct` e `deleteProduct`;
- Testes de contrato para categorias e produtos.

O exercício solicitava a criação de um repositório separado.
