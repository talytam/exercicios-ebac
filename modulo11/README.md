# Módulo 11 - Automação de UI com Cypress

Exercício de automação de testes Web na EBAC Shop utilizando Cypress.

## Cenários automatizados

Os testes contemplam:

- login com sucesso e cenários de credenciais inválidas;
- logout;
- pré-cadastro com geração de dados;
- seleção de produtos;
- adição e remoção de produtos do carrinho;
- validação de produto fora de estoque;
- adição de produto à lista de desejos.

## Tecnologias

- Cypress
- JavaScript
- Faker

## Execução

Instale as dependências:

```bash
npm install
```

Execute os testes:

```bash
npx cypress run
```

Para abrir a interface do Cypress:

```bash
npx cypress open
```
